## 1. 背景

bearko.games 共通基盤の RTA に参加する。区切りが明確（レベルのクリア）なので、レベル 01〜09 を続けてクリアするまでを測る。

## 2. ルール（作者の決定 2026-10-17）

| 項目 | 中身 |
|---|---|
| レギュレーション | `fortress-all`（共通基盤の `platform/rta.js`） |
| セーブ | **新しいセーブ（引き継ぎなし）**。音量と幻獣の見た目だけ引き継ぐ。会話はすべて既読にする（読み飛ばす手間を全員そろえる） |
| 倍速 | **3 倍に固定**。スキルツリーの「ライトフライヤー号」（3 倍速の解放）の前でも 3 倍。テスト用の 5 倍速は使えない（一時停止メニューに出さない） |
| 始まり | ホームの「RTA」→ 確認 →「始める」で計測を始め、すぐにレベル 01 のランへ |
| 区切り | 各レベルの **最初のクリア**（`L1`〜`L8`、レベル 09 は `clear`）。負け・撤退・同じレベルの 2 回目のクリアは送らない |
| IGT | レベルを遊んだゲーム内時間の合計（負け・撤退のランも含む。ミリ秒） |
| 終わり | レベル 09 のクリアで完走。ホームの「RTA をやめる」で中断。再読み込みすると計測は消える（SDK の計測がメモリだけのため） |

- シミュレーションは固定の刻みで進むので、倍速で結果は変わらない。上限を決めれば全員がその速さで走ることになるので、固定にした
- 負けてもやり直せる。スキルツリーを育てる時間も含む（実時間）

## 3. 仕様

### 3.1 RTA 用のセーブ

- ふだんのスロット（`mcf.v2.slot.1〜3`）とは別のキー `mcf.v2.slot.rta` に保存する。RTA を始めるたびに作り直す
- **ふだんのセーブには触らない**（上書きの確認は要らない）。計測が終わる（完走・中断・再読み込み）と、ホームに戻ったときにふだんのセーブに戻る
- 起動時は、いつもどおり最後に使ったスロット（`activeSlot`）を読む。RTA 用のセーブが `activeSlot` になることはない
- RTA 用のセーブで取ったトロフィー・総合スコアも、ふだんどおり共通基盤に送る（総合スコアは共通基盤が前回の自己ベストと束ねるので下がらない。SPEC-122）

### 3.2 画面

- ホームのヘッダー：「RTA」ボタン（計測中は「RTA をやめる」）。右上のスロットの表示は計測中「RTA 計測中」
- 確認：ルール（新しいセーブ・3 倍速固定・負けてもやり直せる・いまのセーブは残る・再読み込みで消える）
- SDK が読めない・通信に失敗したら RTA は始めない（「RTA は bearko.games につながっているときだけ遊べます」）。ゲームはふだんどおり遊べる
- 経過時間・区間タイム・結果の通知・15 分の無操作（参考記録）は共通基盤の SDK が出す（タイマーは画面の上）

### 3.3 レイヤ

- 区切り・IGT・RTA 用のセーブの中身は `meta/rta.ts`（純関数。Phaser・window に依存しない）
- SDK を呼ぶのは `view/platform.ts`（`startRta`・`rtaCheckpoint`・`abortRta`）。失敗しても例外を出さない

## 4. 受け入れ基準

- [ ] ホームの「RTA」→「始める」でレベル 01 が 3 倍速で始まり、上に RTA のタイマーが出る。速度ボタンは 3x のまま変わらず、一時停止メニューに 5 倍速が出ない
- [ ] レベル 01 をクリアすると「RTA レベル 01 クリア」の区間タイムが出る
- [ ] レベル 09 をクリアすると完走し、`https://bearko.games/rta/` に載る（ログイン時）
- [ ] 「RTA をやめる」でいつものセーブに戻り、いつものセーブの進み具合は変わっていない
- [ ] SDK が読めない状態では RTA が始まらず、ふだんどおり遊べる

## 5. テスト

- `web/src/meta/rta.spec.ts`：区切りの順番（負け・2 回目のクリア・順番違いは送らない）、IGT、RTA 用のセーブ（引き継ぎなし）
- `web/src/meta/save.spec.ts`：RTA 用のセーブはふだんのスロットと別のキー
- `web/src/view/platform.spec.ts`：SDK がない・失敗・例外でも止めない
- ブラウザ（共通基盤の `tools/e2e/server.mjs` と組み合わせ）：「RTA」→「始める」で計測が始まり（`fortress-all`）、RTA 用のセーブが別のキーにでき、3x で始まる。区切り `L1` が受け付けられる
