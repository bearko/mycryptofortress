## 1. 画面構成（論理 720×1280）

| 領域 | y | 内容 |
|------|---|------|
| HUD | 0–112 | 幻獣アイコン + HP バー、WAVE n/10、GUM 残高 |
| 盤面 | 112–1072 | 9×12 マス（80px）。背景（暗幕付き）、経路、ビルドマス、幻獣、ヒーロー、敵、弾、GUM ドロップ、演出 |
| 下部パネル | 1072–1280 | 選択に応じて切り替わる操作パネル（§2） |

## 2. 操作

| 操作 | 結果 |
|------|------|
| 空きマスをタップ | 配置パネル（ロビンフッドの性能 + 「配置 50 GUM」） |
| ヒーローをタップ | ヒーローパネル（Lv・攻撃・射程・間隔・累計ダメージ、狙い切替、強化）。盤面に現在の射程（実線）と次レベルの射程（薄い円）を表示 |
| 盤面の何もない所をタップ | 選択解除 |
| 盤面をなぞる / カーソルを重ねる | GUM 回収 |
| 敵・ヒーローを長押し | 詳細ツールチップ（敵: 名前・HP・速度） |
| 下部パネル（未選択時） | 「Wave 開始」（開始前・休憩中）、速度 1x / 2x、メニュー（一時停止 → 再開 / 撤退） |

## 3. 表現

- ヒーロー: MCH ドット絵（64px → 1.15 倍）。標的の方向を向き、攻撃時に踏み込む。レベルバッジ。
- 敵: MCH ドット絵。移動方向に反転、被弾で白く点滅、HP バー（減っている時のみ）。ボスは 1.6 倍 + 赤いオーラ。
- 撃破: MCH バトルエフェクト `01_single_damage` を再生。
- 幻獣: 被弾でフラッシュと画面の揺れ。
- Wave 開始バナー、ボス Wave は赤い「BOSS」警告。

## 5. リザルト

勝敗、到達 Wave、撃破数、獲得 GUM、残り HP、ヒーロー別の与ダメージ。「もう一度」「ホームへ」。（トークン報酬は Phase 2 / SPEC-106）
