## 1. 役割

Outhold のパルスタワー相当の**サポート**。範囲内の全員を鈍足にし、近くの味方を速くし（充電）、鈍足の敵同士をダメージでつなぐ（ダメージリンク）。

## 2. 性能（Lv1）

| 項目 | 値 |
|------|-----|
| 配置 | 60 GUM（強化 55 / 90 / 145 / 230） |
| 攻撃 / 間隔 / 範囲 | 3 / 1.6 秒 / 1.7 マス（Lv ごとに ×1.4 / ×0.94 / +0.12） |
| 鈍足 | 30%・1.5 秒（範囲内の全員） |
| 撃つ条件 | 範囲に敵がいるときだけ（空撃ちしない） |
| 狙い | なし（パネルに狙いボタンを出さない） |

## 3. ツリー（結界の系統）

| ノード（MCH スキル名） | 効果 |
|------------------------|------|
| 急急如律令（安倍晴明） | **解放** |
| タクティクス / 五事七計 / ストラテジー | 鈍足 +8% / 範囲 +0.2 / 攻撃力 +25%（各 Lv） |
| 石化の呪い / メドゥーサの呪い | 波動で 0.5 秒スタン（確率 8% / Lv）/ 鈍足の持続 +0.5 秒 |
| 死せる孔明生ける仲達を走らす（諸葛亮） | **諸葛亮に交代**。波動を受けた敵が**脆弱**（被ダメージ +15%・2 秒） |
| **電気伝導**（グラファイト） | **充電**: 結界の範囲内にいる他のヒーローの攻撃間隔 −10% / Lv（上限 50%） |
| **連環の計**（貂蝉） | **ダメージリンク**: 鈍足中の敵へのヒーローの命中ダメージのうち 10% / Lv を、他の鈍足中の敵全員にも与える |

- 充電・ダメージリンクは Outhold 解析レポート（ユーザー提供）の「パルスの充電バフ」「スロー × 脆弱 × ダメージリンク」を取り込んだもの。
- ダメージリンクは継続ダメージ・リンク自身からは再度伝わらない（無限連鎖の防止）。

## 4. 受け入れ基準

- [x] 範囲内の全員を鈍足にし、敵がいなければ撃たない（テスト）
- [x] 鈍足で移動が遅くなる、ボスは半分（テスト）
- [x] 諸葛亮で脆弱が付く（テスト）
- [x] 充電は範囲内のヒーローだけ、上限 50%、結界自身には掛からない（テスト）
- [x] ダメージリンクは鈍足中の敵にだけ伝わる（テスト）
