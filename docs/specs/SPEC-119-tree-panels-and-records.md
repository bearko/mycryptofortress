## 1. 目的

Outhold のスキルツリーの見た目と動機づけに寄せる。

- パネルの形で「何で解放するか」がひと目で分かるようにする。
- 「GUM をたくさん集める」「ノードを進める」「ボスを倒す」など、CE 以外の遊び方にもごほうびを付ける。無料で解放される条件つきパネルを置く。

## 2. パネルの形

| 形 | 意味 | 解放 |
|----|------|------|
| **四角**（角丸） | 通常のパネル | CE で買う（返金は無料） |
| **四角 + 上辺の紋章** | 新しい能力の解放（ロール・ヒーロー交代・魔石・幻獣砲・Wave 繰り上げ） | エンブレムで買う。パネル自身の上辺に、エンブレムと必要な枚数を重ねて表示する。取得後は消える |
| **丸** | 条件つきパネル | 記録が条件に届くと、プレイヤーがタップして**費用 0 で**解放・強化できる（v1.2 で自動解放から変更）。届いたしきい値の数までしか上げられない。単独では返金されない。外周の金の弧が次のしきい値までの進み具合 |

- **手動で解放する理由（v1.2）**: 気づかないうちに解放されると効果を実感できないため、プレイヤー自身が解放し、何が強くなったかを確かめる形にした。
  - 解放すると、効果をパネルの上に浮かべ、トーストでも知らせる（「〇〇を解放！ 弓の攻撃力 +5%」）。
  - 丸パネルも四角と同じく、親を解放してから解放できる。効果も、親が解放済みのときだけ効く。
- 丸パネルの子（四角）は、丸を 1 レベル以上にすると買える。「記録を伸ばすと新しい強化が開く」形になる。
- 詳細パネルには、条件（しきい値の列と現在値）を出す。解放できるときは「無料で解放 / 無料で強化」、まだのときは「あと N で解放できます」を出す。
- ツリー画面の下部に、解放できる丸パネルがあれば「▶ 無料で解放できます: 〇〇」（緑）を出す。なければ「もうすぐ解放」（進み具合が一番大きい丸パネル）を出す。どちらもタップするとそのパネルへ移動する。
- 「記録と解放」ボタンで、丸パネルの一覧と進み具合のバーを見られる（旧「マイルストーン」一覧を置き換え）。
- リザルトで、新しく解放できるようになった丸パネルを知らせる（「スキルツリーで解放できます: 〇〇」）。

## 2a. 段階的に広がるツリー（v1.1）

パネルを解放してツリーを大きくしていくワクワク感を出すため、見えるパネルを絞り、広がる様子を演出する。

- **表示するパネル**: ルートと、「表示中で 1 レベル以上」のパネルの子だけ（`visibleNodes()`）。最初は「黄金の工房」だけが見え、解放するたびに 1 段ずつ広がる。返金すると先の枝はしぼんで隠れる。
- 条件を満たした丸パネルでも、親が見えて解放済みになるまでは隠れる。効果はその間も効く。「記録と解放」の一覧には全部出る。
- **枠の色**:

  | 状態 | 枠 |
  |------|----|
  | 今すぐ強化できる | **緑**（脈動する光） |
  | 未解放で、CE・エンブレム・条件が足りない | **赤** |
  | 解放済み | 系統の色 |
  | 最大レベル（v1.2） | 目立たせない: 系統の色を薄く・細い枠、塗りも薄く、アイコンも暗く、バッジは灰色の「MAX」。緑・赤のパネルに目が行くようにする |

- **広がる演出（神経網）**:
  - 線は少し曲がった神経のような線にした。親から子へ 0.52 秒かけて伸び、先端が光る。伸び切るとパネルが弾むように開き、光の輪が広がる。
  - 兄弟のパネルは 0.11 秒ずつずらし、枝分かれしながら伸びていく。
  - 新しいパネルが画面外なら、見える位置までゆっくり寄せる。
- **信号**: 表示中の線には、親から子へ光の粒が流れ続ける（解放済みの線は明るく）。
- 前回ツリー画面で見えていたパネルを覚えておき、ランの後などに増えた分は開いたときに広がる。
- 効果音: 広がるときに `se.production`。

## 3. 累計記録（セーブ v6）

`meta.stats` にランをまたいで積み上がる記録を持つ。勝敗・撤退に関係なく足す。

| 記録 | 内容 |
|------|------|
| `kills` | 撃破数 |
| `bossKills` | ボス撃破数。分裂ボスは最後の 1 体、多節ボスは頭で 1 体と数える |
| `gumCollected` | ランで得た GUM（回収・採掘・利息など。開始 GUM と Wave 報酬は除く） |
| `wavesCleared` | クリアした Wave 数 |
| `flawlessClears` | 到達ダメージを一度も受けずにクリアした回数（無効化した到達は数えない） |
| `runs` | 挑戦回数 |

条件には、上の記録と既存の値も使う。

- `levelsCleared`: クリア済みノード数
- `ceEarned`: 累計獲得 CE

v5 → v6 の移行では、挑戦回数だけをレベルごとの記録から復元し、ほかは 0 から数える。

## 6. 配置

- 既存の配置（系統ごとに放射状）を 1.2 倍に広げ、空いた場所へ新しいパネルを置いた。新しいパネルは親の近くに置き、線が他のパネルに重ならないようにした。
- 格子に並べ直す案も試した。弓の系統が大きく、上半分が入り組んで読みにくくなるため見送った。
- ツリーの版（`TREE_VERSION`）は 6。古い版のセーブは全返金する。すでにツリーを見た人には、パネルの形の説明（`tree.panels`）を 1 度だけ出す。

## 7. 調査の範囲

Outhold のパネルの効果と依存関係を網羅したガイド（Steam ガイド・攻略サイト）は、この環境のネットワーク制限で本文を読めなかった。取り込んだのは、検索結果の要約で確かめられた次の要素だけである。

- 印 / 自動マーク / 弱点を突く / 多重会心 / 報復の炎 / 銀行（利息）
- 弓から雷への派生
- 重い矢
- レベルクリアによる解放

ネットワークを許可したあとに追加で調べ、ツリーの構成を寄せる（§8）。
