## 1. 仕様

- 「アメン・ラーの陽光」で解放。**幻獣から指の方向へ貫通する光線**を撃つ。
- 1 発ごとに GUM を消費し、クールダウンがある。

| 項目 | 値 |
|------|-----|
| 消費 | 3 GUM（「ヒーリングライト」で −1 / Lv、下限 1） |
| ダメージ | 6（「太陽神の涙」で +30% / Lv） |
| 光線の半幅 / 長さ | 0.45 マス（「ドルイドの秘法」で +0.15 / Lv）/ 14 マス |
| クールダウン | 0.25 秒 |
| 黄金の炎 | 当たった敵に炎上（毎秒 2・2 秒） |

## 2. 操作（スマホ縦画面）

- 下部パネルの「幻獣砲」ボタンで ON / OFF。ON の間は、盤面を押している（なぞっている）方向へクールダウンごとに撃ち続ける。
- ON の間は盤面タップでマスを選ばない（誤操作防止）。GUM の回収はそのまま行える。
- 光線は盤面の外（HUD・パネル）には描かない。

## 3. 受け入れ基準

- [x] 解放前は撃てない。GUM を消費し、光線上の敵を貫通してダメージ、クールダウンあり（テスト）
- [x] GUM が足りなければ撃てない（テスト）
- [x] リザルトに幻獣砲のダメージを表示する
