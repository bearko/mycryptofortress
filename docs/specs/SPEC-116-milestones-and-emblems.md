## 1. エンブレム（SPEC-116a）

Outhold の「三角トークン（能力値）/ 星トークン（新しい能力の解放）」の二層構造を取り入れる。

| トークン | 入手 | 使い道 |
|----------|------|--------|
| CE | 毎ラン（勝敗問わず、到達 Wave に比例） | 能力値を伸ばすノード |
| **エンブレム**（MCH のエンブレム） | **各レベルの初回クリア**（Lv1〜2: 1、Lv3〜5: 2、Lv6〜8: 3、Lv9: 4。計 21） | **新しい能力の解放**: ロール解放（雷・結界・炎・採掘）・幻獣砲・Wave 繰り上げ・魔石 4 種（各 1）、ヒーロー交代 6 種（各 2）。計 22 |

- 全部は買えない（1 つ足りない）ので、どの能力を解放するかを選ぶ。返金は無料なので組み替えられる。
- ツリーではエンブレムで買うノードにエンブレムのバッジを付け、ボタンに「解放 1 エンブレム」と出す。
- ヘッダー（ツリー・ノード選択）とリザルトに所持数 / 獲得数を出す。初めて手に入れた時はマインちゃんが説明する。

## 2. マイルストーン（SPEC-116）

> **v1.2**: マイルストーンはスキルツリーの丸パネル（条件つきパネル）4 枚に置き換えた（[SPEC-119](./SPEC-119-tree-panels-and-records.md)）。閾値と効果は同じ。一覧は「記録と解放」から見る。

累計獲得 CE が閾値を超えると**無料で**解放される便利機能（Outhold の Free Milestones）。返金の対象外。

| マイルストーン | 閾値（累計 CE） | 効果 |
|----------------|-----------------|------|
| GUM 自動回収 | 120 | 落ちた GUM が 0.5 秒後に自動で集まる（`autoCollect` 補正） |
| ビルドセット | 300 | ツリーの配置を 5 枠まで保存・読込・消去 |
| 倍速 3x | 600 | 速度ボタンに 3x が加わる |
| オートレベル | 1000 | ラン中、足りる GUM で一番低いレベルのヒーローを強化（一時停止メニューで ON/OFF、設定に保存） |

- ツリー画面の「マイルストーン」で一覧と残り CE を見られる。リザルトで新しく届いたらお知らせする。
- **テストプレイ用 5 倍速**: 一時停止メニューの「5 倍速（テスト用）」を ON にすると、速度ボタンに 5x が加わる（マイルストーンとは無関係。`settings.testSpeed` に保存）。

## 3. ビルドセット

- 保存: 今のツリー（ノード → レベル）を枠に保存する。
- 読込: **全返金してから**、保存したノードを親から順に買い直す。トークンが足りない分は買えるところまでにして、足りなかったレベル数を知らせる。

## 4. セーブ v5

- `meta.tokens` / `meta.tokensEarned` に `emblem` を追加。v4 からの移行では、クリア済みレベルの初回クリア分のエンブレムを付与する。
- `meta.buildSets`（5 枠、空きは null）、`settings.autoLevel` を追加。
- ツリーの版（`TREE_VERSION`）は 5。古い版のセーブは CE・エンブレムとも全額返金してホームで知らせる。

## 5. 受け入れ基準

- [x] 初回クリアでエンブレムが入り、2 回目は入らない。解放ノードはエンブレムで買い、返金はトークンごとに戻る（テスト）
- [x] ビルドセットを保存・読込でき、読込は全返金してから買い直す（テスト）
- [x] マイルストーンは累計 CE で解放され、自動回収はランに効く（テスト）
- [x] v4 → v5 の移行でエンブレム・ビルドセット枠・オートレベル設定が入る（テスト）
