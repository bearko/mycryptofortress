## 1. 目的と変更点

Outhold の元素アーティファクト（タワーに属性を付けると挙動が変わる）に相当する仕組み。

- SPEC-100 では「五神獣の宝珠（5 勢力）」としていたが、MCH の素材に勢力の宝珠の画像がない。一方、MCH の素材「魔石」に **4 属性の公式画像**（イフリート / リヴァイアサン / ティアマト / ガルーダ）がある。
- **アセット原則（MCH の素材を使う）を優先し、4 種の魔石に変更**した。5 つ目の元素（光）が担うはずだった「射程・隠密の看破」はガルーダ（風）に統合した。

## 2. ルール

- ツリーの魔石ノード（エンブレム 1 つずつ）で解放する。1 ランにつき各魔石 **1 個**。
- ラン中、ヒーロー（またはタップした幻獣 = 幻獣砲）に **1 つだけ**装着できる。付け替え・取り外しは自由（無料）。
- **属性マス**（レベル定義の `slots[].element`）に置いたヒーローは、魔石なしでその属性を得る。属性マスのヒーローには魔石を付けられない。Lv7〜9 に 2〜3 マスずつある。

## 3. 効果（★ = 攻撃の挙動が変わる）

| 装着先 | イフリート（炎） | リヴァイアサン（水） | ティアマト（地） | ガルーダ（風） |
|--------|------------------|----------------------|------------------|----------------|
| 弓 | ★火矢: 命中で小爆発（半径 0.8・50%）＋炎上 | 命中で鈍足 25% | 命中で必ず毒・攻撃力 +15% | ★疾風: 毎回 2 体に撃つ・攻撃速度 +15% |
| 雷 | 連鎖した敵を炎上 | ★放電で 0.8 マス押し戻す＋鈍足 | ★毒連鎖: 連鎖した敵すべてに毒 | 連鎖 +2・跳ぶ距離 +0.6 |
| 結界 | ★炎の結界: 範囲の全員を炎上 | 鈍足 +15%・スタン確率 +10% | ★毒の結界: 範囲の全員に毒 | ★波動の間隔 ×0.6 |
| 炎 | 炎上の積み上げ +30%・上限 +50% | ★冷炎: 炎を浴びた敵が鈍足 | 炎の攻撃力 +30% | ★十字火球: 1 秒ごとに縦横 4 方向へ貫通する火（射程 +2 マス・×1.5） |
| 採掘 | ★焼き討ち: 通行料を払った敵を炎上 | ★渦潮: 通行料を払った敵が鈍足 35% | ★地脈: 通行料 ×2 | 範囲 +0.8・配当 +50% |
| 幻獣砲 | 光線が炎上を与える | 光線が鈍足を与える | 光線が毒を与える | 光線の太さ ×1.5 |

- 各ロールに挙動が変わる組み合わせが 2 つ以上ある（Phase 4 の完了条件）。
- **ガルーダを持つヒーローの射程内では、隠密の敵（SPEC-117）が見える。**
- 数値は `STONE_NUM`（`stones.ts`）にまとめる。

## 4. UI

- ヒーローパネルに「魔石」ボタン（解放済みのときだけ）→ 魔石カード 4 枚。タップで装着 / 付け替え / 外す、長押しでそのロールでの効果。
- 幻獣をタップすると幻獣砲のパネル（「魔石を装着」）。
- 盤面: 属性マスの右上とヒーロー・幻獣の足元に魔石のしるし。

## 5. 受け入れ基準

- [x] 解放した魔石だけ装着でき、付け替えで前の持ち主から外れる。幻獣砲にも付けられる（テスト）
- [x] 属性マスは魔石なしで属性を得て、魔石は付けられない（テスト）
- [x] 各ロールの挙動変化（火矢・疾風・押し戻し・毒連鎖・毒の結界・十字火球・冷炎・渦潮・焼き討ち）と幻獣砲の効果（テスト）
