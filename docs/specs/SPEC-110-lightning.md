## 1. 役割

**連鎖する範囲攻撃**と**足止め（放電）**。密集した敵に強く、単体には弓に劣る。

## 2. 性能（Lv1）

| 項目 | 値 |
|------|-----|
| 配置 | 70 GUM（強化 60 / 100 / 160 / 250） |
| 攻撃 / 間隔 / 射程 | 7 / 1.1 秒 / 2.0 マス（Lv ごとに ×1.45 / ×0.93 / +0.15） |
| 連鎖 | 初撃の後に **2 回**跳ぶ（跳ぶ距離 1.6 マス、1 跳びごとに −35%） |
| 感電 | 命中ごとに +1。**5** で放電 → 0.6 秒スタン |

## 3. ツリー（雷の系統）

| ノード（MCH スキル名） | 効果 |
|------------------------|------|
| 凧とライデン瓶の雷実験（フランクリン） | **解放** |
| ノービスブライト | 雷の攻撃力 +15% / Lv |
| エリートブライト | 連鎖 +1 / Lv |
| ウィズダムブライト | 感電 +1 / 命中 |
| テスラコイル（テスラ） | **ニコラ・テスラに交代**、連鎖 +1、攻撃力 +20% |
| 不思議な光 | 放電のスタン +0.3 秒 / Lv |
| 希望の燐光 | 放電の瞬間にその 1 撃 ×3 の追加ダメージ |

## 4. 受け入れ基準

- [x] 連鎖して複数の敵に当たり、感電が閾値に達すると放電してスタンする（テスト）
- [x] 連鎖数の補正で跳ぶ回数が増える（テスト）
- [x] 演出: ヒーロー → 敵 → 敵のギザギザの稲妻、放電で「放電!」
