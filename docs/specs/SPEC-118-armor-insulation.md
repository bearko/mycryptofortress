## 1. 背景（プレイテスト）

- Lv3 以降、雷だけでほとんど苦戦せずに勝ててしまった。雷は単体への DPS でも弓を上回り、しかも連鎖と放電があった。
- 要望: 「弓が雷に勝っているところ」と「雷一辺倒ではクリアできないギミック」。

## 2. 変更

| 項目 | 内容 |
|------|------|
| 雷の性能 | 攻撃 7 → **6**、間隔 1.1 → **1.25 秒**（単体 DPS 6.4 → 4.8。弓は 6.25）。群れへの連鎖は強いまま |
| **装甲**（新） | 1 発ごとのダメージを固定値だけ減らす（最低 20% は通る）。装甲値 = 基本値 × √(Wave の HP 倍率)。**炎上・毒・爆発・誘爆は素通り** |
| 弓の強み | **矢は装甲を半分無視**（崩城の一撃は全部無視）。単体 DPS・射程・会心・ボス特効と合わせて、硬い敵とボスは弓の役割 |
| **絶縁**（新） | 雷のダメージ ×0.25、感電しない（連鎖は通り抜けて後ろの敵に跳ぶ） |
| 幻獣砲 | 装甲を半分無視 |

## 3. 新しい敵

| 敵（MCH） | 画像 | 特徴 | 登場 |
|-----------|------|------|------|
| エルククローナ ショート / トール | 111 / 112 | 装甲 3 / 5 | Lv3〜 |
| メリッサ ショート / トール | 131 / 132 | 絶縁 | Lv5〜 |

- Lv3〜9 の Wave に混ぜ、各レベルの HP 倍率を再調整した（自動プレイヤーで Lv9 まで約 76〜85 ラン）。

## 4. 確認（自動プレイヤー、各レベルに初めて挑む時点のツリーで 4 シード）

| レベル | 混成 | 雷ばかり | 弓ばかり |
|--------|------|----------|----------|
| Lv3 | Wave 5.0 | Wave 3.0 | Wave 6.0 |
| Lv5 | Wave 9.0 | Wave 4.3 | **4/4 勝利** |
| Lv7 | **Wave 9.3（1 勝）** | Wave 6.5 | Wave 7.8 |
| Lv9 | Wave 4.3 | **Wave 8.3** | Wave 3.5 |

- 雷ばかりは装甲・絶縁の多いレベルで最も弱く、群れの多い Lv9 では最も強い。レベルごとに有利な編成が変わる。
