## 1. 概要

ラン（1 レベルの挑戦）の戦闘を、Phaser に依存しない**決定的シミュレーション** `RunSim`（`web/src/sim/`）として実装する。描画側は `RunSim` にコマンドを送り、毎フレーム状態とイベントを読むだけにする。

## 2. 契約と挙動

### 2.1 時間

- 固定タイムステップ `TICK = 1/30 秒`。`step()` で 1 tick 進む。倍速は描画側が 1 フレームに複数回 `step()` を呼ぶ。
- 乱数は `Rng(seed)` のみ（`Math.random` 禁止）。**同じレベル・シード・同じ tick に同じコマンド列 → 同じ結果**。

### 2.2 座標

- 単位は**マス**。マス (col,row) の中心は `(col+0.5, row+0.5)`。描画側で px に変換する。
- 経路はマス中心を結ぶ折れ線。敵は経路上の距離 `dist` で位置が決まる。見た目の重なりを避けるため、敵ごとに経路の法線方向へ ±0.18 マスのオフセット（乱数）を持つ。

### 2.3 状態

| 状態 | 内容 |
|------|------|
| `status` | `prep`（開始前）→ `running` → `won` / `lost` |
| Wave | `waveIndex`（0 始まり、開始前は -1）。Wave の全出現が終わり盤面の敵が 0 になると**クリア**し、Wave 報酬 GUM を付与して `intermissionSeconds` の休憩へ。最終 Wave クリアで `won` |
| 休憩 | `nextWaveIn` 秒後に次 Wave を自動開始。`startNextWave()` で即開始できる（開始前・休憩中のみ。Phase 1 ではボーナスなし） |
| 幻獣 | `hp` / `maxHp`。敵が経路の終点に到達すると `leak` 分減る。0 以下で `lost` |
| GUM | 撃破時にドロップ（`drops`）。`collectDropsAt(x, y, r)` で半径内を回収。`dropLifetime`（10 秒）で消滅 |

### 2.4 ヒーロー

- `placeHero(slotIndex, roleId)`: 空きスロットに配置（GUM 消費）。`levelUp(heroId)`: 最大レベルまで強化（GUM 消費）。
- 攻撃: クールダウンが 0 になったら射程内から標的を選び、**追尾弾**を撃つ。命中時にダメージ。標的が命中前に倒れた場合、弾は最後の位置で消える。
- **撃ちすぎ防止**: 飛翔中の弾の予定ダメージ（`pending`）で倒せる敵は、他に候補がある限り標的にしない（Outhold の「何もない所を撃つ」不満への対策）。
- **ターゲット優先度** `setTargetMode(heroId, mode)`:

| mode | 選び方 |
|------|--------|
| `first`（既定） | 幻獣までの残り距離が最小 |
| `strong` | 現在 HP が最大 |
| `weak` | 現在 HP が最小 |
| `close` | ヒーローに最も近い |
| `boss` | ボスを優先、いなければ `first` |

同点は敵 ID の小さい方（決定性のため）。

### 2.5 イベント

`drainEvents()` で前回以降のイベントを取り出す: `waveStart` / `waveClear` / `spawn` / `attack` / `hit` / `kill` / `leak` / `drop` / `collect` / `dropExpire` / `heroPlaced` / `heroLevelUp` / `won` / `lost`。描画・SE・演出はイベントから起こす。

### 2.6 統計

撃破数、到達数、獲得 GUM、ヒーロー別の累計ダメージ。リザルト画面（SPEC-105）で表示する。

## 3. 受け入れ基準

- [x] 同一シード・同一コマンド列で状態が完全一致する（テスト）
- [x] 何もしないと Lv1 で `lost`、簡易ボット（配置 → 強化 → 回収）で複数シードとも `won`（テスト）
- [x] ターゲット優先度 5 種・撃ちすぎ防止・GUM 回収 / 消滅・Wave 進行のテスト
- [x] `sim/` は Phaser を import しない
