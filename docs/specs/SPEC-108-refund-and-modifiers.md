## 1. 無料返金

- **1 レベル返金**: そのレベルの費用を全額返す。レベル 0 になる場合、**子孫ノードもすべて返金**する（親が 0 のノードは効果を持てないため）。
- **全返金**: 使用中の CE をすべて返し、ツリーを空にする。
- 返金にペナルティはない（Outhold と同じく実験を罰しない）。

## 2. 補正値（RunModifiers）

ツリーの効果は `computeModifiers(save)` で **加算合成**した `RunModifiers`（`web/src/sim/modifiers.ts`）になり、`new RunSim(level, seed, mods)` に渡す。RunSim はツリー構造を知らない。

- 未知のノード ID は無視、レベルは最大で切る、親が 0 のノードは無効（セーブ破損・データ変更への耐性）。
- 適用先:

| 分類 | 補正 | RunSim での扱い |
|------|------|----------------|
| 弓 | 攻撃力 / 攻撃速度 / 射程 | `statsFor()` の性能に反映（プレビューにも表示） |
| 弓 | 会心率・会心ダメージ | 発射時に乱数で確定（決定性を保つ） |
| 弓 | 追加の矢 / 一斉射撃 | 2 本目は別の標的、一斉射撃は最大 3 体（×0.55） |
| 弓 | ボスへのダメージ / 所持 GUM 補正 | 発射時に掛ける |
| 弓 | 配置コスト / 強化コスト | `placeCost()` / `levelUpCost()`（下限あり） |
| 幻獣 | 最大 HP / Wave 回復 / 自然回復 | 最大 HP を超えない |
| 幻獣 | 到達無効化 / 聖女の祈り | ボス以外は確率で無効、ボスは 1 回だけ HP 1 で耐える |
| 経済 | 開始 GUM / 撃破 GUM / 回収範囲 / 消滅時間 / Wave 報酬 / 命中 GUM | GUM の出入りに反映 |

## 3. 受け入れ基準
