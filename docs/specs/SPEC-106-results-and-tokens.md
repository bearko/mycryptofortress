## 1. 概要

ランの結果に応じてメタ通貨 **CE（クリプトエナジー）**を付与し、セーブに記録する。**負けても・撤退しても、クリアした Wave 分の CE は必ずもらえる**（Outhold の「負けても進む」）。レベルは前のレベルをクリアすると解放される。

## 2. CE 報酬

各レベルの `reward`（`web/src/data/levels/*.json`）で決める。

| 内訳 | 条件 | Lv1 | Lv2 | Lv3 |
|------|------|-----|-----|-----|
| Wave クリア | クリアした Wave 1 つごと | 3 | 3 | 4 |
| 防衛成功 | レベルをクリア | 20 | 25 | 35 |
| 初回クリア | そのレベルを初めてクリア | 30 | 30 | 40 |

- 撤退（メニュー → 撤退する）も、クリアした Wave 分を受け取ってリザルトへ進む。
- リザルトには獲得 CE と内訳、マイクリくんの実況（SPEC-108a）を表示する。
- **ボタンは「スキルツリーで強化」（主ボタン）と「もう一度」の 2 つ**（Outhold の「アップグレード / もう一度プレイ」に倣う）。強化せずに再挑戦して同じ負け方を繰り返さないよう、スキルツリーを大きく金色にし、買えるスキルがあるときは「強化できるスキル N 個」を表示して脈動させる。ホームへ戻るボタンは置かない（スキルツリー → ← でホームへ戻れる）。
- リザルトからスキルツリーへ来た場合、ツリー画面に「▶ 再挑戦」ボタンを出し、強化後にそのまま同じレベルへ再挑戦できる。

## 3. レベル進行

- `LevelProgress`: クリア済み・最高到達 Wave・クリア回数・挑戦回数。
- Lv1 は最初から解放。Lv(n+1) は Lv(n) のクリアで解放。
- ステージ選択画面（ノードを選ぶ）: 各レベルのボス・入口数・Wave 数・進行状況・CE 報酬を表示。未解放は鍵表示。クリスくんがランダムにヒントを話す。

## 4. 到達可能性の自動検証

`meta/campaign.ts` の自動プレイヤー（ラン前に標準の購入順でツリーを買い、未クリアの最初のレベルに挑む）で次を保証する。

- 1 回目は Lv1 の Wave 2 で負ける（それでも CE が入る）。
- Lv1 はすぐには勝てず（4 敗以上）、負けるたびに到達 Wave が伸びる。
- 強化なしでは Lv2・Lv3 を突破できない。標準の購入順で 26 ラン以内に Lv3 までクリアできる。
- 参考: 調整時は Lv1 クリア 9 回目、Lv2 13〜15 回目、Lv3 19〜20 回目。等倍で約 60 分（2 倍速ならおよそ半分）。

## 5. セーブ（スキーマ v3）

`SaveData.meta` を追加し、v1 → v2 のマイグレーションで既存セーブ（選んだ幻獣・音設定）を引き継ぐ。v2 → v3 はスキルツリーの構成変更に伴い**ツリーを全返金**する（所持 CE = 累計獲得 CE に戻す）。

```ts
meta: {
  tokens: { ce: number };          // 所持
  tokensEarned: { ce: number };    // 累計
  tree: Record<string, number>;    // ノード ID → レベル（SPEC-107）
  levels: Record<string, { cleared; bestWave; clears; runs }>;
  seenDialogs: string[];           // 既読の会話（SPEC-108a）
}
```

## 6. 受け入れ基準

- [x] 負け・撤退でもクリアした Wave 分の CE が入り、初回クリアボーナスは 1 回だけ（テスト）
- [x] Lv2 は Lv1 クリアで解放（テスト・画面確認）
- [x] v1 セーブが v2 に移行する（テスト）
- [x] 自動プレイヤーで Lv3 までクリア可能（テスト）

## 画面遷移の改善（プレイテスト反映）

- リザルトの左ボタン: そのノードをクリア済みなら「**次のノードへ**」（次の未クリアのノードをすぐ始める）、未クリアなら「もう一度」。
- リザルトからスキルツリーへ行った場合: 「**▶ 次のノードへ**」（クリア済み時）/「▶ 再挑戦」（未クリア時）と「**ノード選択**」ボタンを出す。ヘッダーの戻るもノード選択へ（ホームを経由しない）。
- ノード選択: レベルが画面に収まらないので、**ドラッグ（スマホ）/ ホイール（PC）でスクロール**でき、最初は次に挑むノードが見える位置に合わせる。
