## 1. 概要

ランの結果に応じてメタ通貨 **CE（クリプトエナジー）**を付与し、セーブに記録する。**負けても・撤退しても、クリアした Wave 分の CE は必ずもらえる**（Outhold の「負けても進む」）。レベルは前のレベルをクリアすると解放される。

## 2. CE 報酬

各レベルの `reward`（`web/src/data/levels/*.json`）で決める。

| 内訳 | 条件 | Lv1 | Lv2 | Lv3 |
|------|------|-----|-----|-----|
| Wave クリア | クリアした Wave 1 つごと | 2 | 3 | 4 |
| 防衛成功 | レベルをクリア | 15 | 25 | 35 |
| 初回クリア | そのレベルを初めてクリア | 20 | 30 | 40 |

- 撤退（メニュー → 撤退する）も、クリアした Wave 分を受け取ってリザルトへ進む。
- リザルトには獲得 CE と内訳、マイクリくんの実況（SPEC-108a）を表示する。「ツリー」「もう一度」「ホーム」へ進める。

## 3. レベル進行

- `LevelProgress`: クリア済み・最高到達 Wave・クリア回数・挑戦回数。
- Lv1 は最初から解放。Lv(n+1) は Lv(n) のクリアで解放。
- ステージ選択画面（ノードを選ぶ）: 各レベルのボス・入口数・Wave 数・進行状況・CE 報酬を表示。未解放は鍵表示。クリスくんがランダムにヒントを話す。

## 4. 到達可能性の自動検証

`meta/campaign.ts` の自動プレイヤー（ラン前に標準の購入順でツリーを買い、未クリアの最初のレベルに挑む）で次を保証する。

- 強化なしでは Lv2・Lv3 を突破できない（スキルツリーが必要）。
- 標準の購入順で 12 ラン以内に Lv3 までクリアできる。途中で負けても CE が入る。
- 参考: 調整時は 7〜9 ラン・等倍で 23〜29 分（2 倍速ならおよそ半分）。

## 5. セーブ（スキーマ v2）

`SaveData.meta` を追加し、v1 → v2 のマイグレーションで既存セーブ（選んだ幻獣・音設定）を引き継ぐ。

```ts
meta: {
  tokens: { ce: number };          // 所持
  tokensEarned: { ce: number };    // 累計
  tree: Record<string, number>;    // ノード ID → レベル（SPEC-107）
  levels: Record<string, { cleared; bestWave; clears; runs }>;
  seenDialogs: string[];           // 既読の会話（SPEC-108a）
}
```

## 6. 受け入れ基準

- [x] 負け・撤退でもクリアした Wave 分の CE が入り、初回クリアボーナスは 1 回だけ（テスト）
- [x] Lv2 は Lv1 クリアで解放（テスト・画面確認）
- [x] v1 セーブが v2 に移行する（テスト）
- [x] 自動プレイヤーで Lv3 までクリア可能（テスト）
