## 1. 採掘ヒーロー

Outhold のバンクタワー相当。**攻撃しない**代わりに GUM を稼ぐ。

| 項目 | 値 |
|------|-----|
| 配置 | 70 GUM（強化 60 / 100 / 160 / 250） |
| 範囲 | 1.8 マス（Lv ごとに +0.1） |
| 通行料 | 範囲を通った敵 1 体につき 1 回だけ、Lv × 1 GUM（即時） |
| 配当 | Wave クリア時に Lv × 4 GUM |

| ノード（MCH スキル名） | 効果 |
|------------------------|------|
| マイニング ALPHA CC（サトシ・ナカモト ALPHA CC） | **解放** |
| みかじめ料 / 資産凍結 / ウィズダム資産凍結 | 通行料 +1 / 配当 +50% / 範囲 +0.3（各 Lv） |
| マイニング OMEGA CC | **OMEGA CC に交代**。通行料 +1・配当 +50% |

## 2. ロックマス

- レベル定義のスロットに `kind: "locked"` と `cost` を書く（SPEC-103 の拡張。バリデータは cost > 0 を要求）。
- ラン中に GUM を払うと開放され、以降は通常のマスとして使える。
- 「騎兵突撃」で開放費用 −20% / Lv。
- Lv4〜6 に 2〜3 マスずつ置く。

## 3. Wave の繰り上げ

- 「一日千里」で解放。**その Wave の出現が終わり、敵が残っていて、最終 Wave でない**ときに呼べる。
- 呼ぶと、残っている敵 1 体につき 2 GUM（「神託の軍馬」で +50% / Lv）のボーナスと、**その Wave のクリア報酬**を先に受け取る。
- 繰り上げで呼んだ Wave の敵は 20% 加速する。
- ボタンは Wave ボタンを兼ねる（「次の Wave ／ 繰り上げ +N GUM」）。

## 4. 受け入れ基準

- [x] 通行料は敵 1 体につき 1 回だけ、配当は Wave クリア時（テスト）
- [x] ロックマスは開放するまで置けず、開放費用はツリーで下がる（テスト）
- [x] 繰り上げは条件を満たすときだけ呼べ、ボーナスと Wave 報酬が入り、敵が加速する（テスト）
