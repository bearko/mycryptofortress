## 1. 背景

ホームの BGM・SE は ON / OFF の 2 択で、小さくして遊ぶことができない。作者の依頼（2026-10-17）
「BGM/SE の音量を全タイトルで 20 段階で設定できるようにしたい」により、Survivor（SPEC-044）・
Factory（SPEC-011）と同じ 20 段階（0〜100% を 5% 刻み。0 は OFF）にそろえる。

## 2. 仕様

| 項目 | 内容 |
|---|---|
| 入口 | ホーム下段の「BGM ON/OFF」「SE ON/OFF」の 2 つを、1 つの「音の設定」ボタンに置き換える（sub にいまの段階 `BGM 60% / SE 80%`） |
| 画面 | 押すと、RTA の確認と同じ暗幕つきのパネル。中に **BGM** と **SE** の行（名前・「−」・いまの段階・「＋」）と「閉じる」。ホームは Phaser の canvas なので、スライダーではなく −/＋ で段を動かす |
| 段階 | 0.05 刻み（0・0.05・…・1 の 21 の位置）。表示は 0 が「OFF」、ほかは「65%」。端で止まり、端の側のボタンは locked の見た目 |
| 保存 | いままでどおりセーブの `settings.bgmVolume` / `settings.seVolume`（0..1）。押した瞬間に保存。既定は 0.6 / 0.8（60% / 80%）のまま。セーブの版は変えない |
| 反映 | BGM は押した瞬間に再生中の曲へ（`playBgm`：0 で止まり、戻すと再開）。SE はステッパーのタップ音を**値を変えたあとに**鳴らし、新しい大きさの試し聞きにする（0 なら鳴らない） |
| 純ロジック | `snapVolume`（5% 刻みに丸め 0..1 に収める）・`stepVolume`（1 段上げ下げ）・`volumeLabel`（表示）。Phaser に依存しない |

- meta・sim・data は触らない（セーブの形は変わらない）。依存は増えない
- `Button` に `silent`（タップ音を鳴らさない）を足す。ステッパーは値が変わったときだけ自分で鳴らす

## 3. 受け入れ基準

- [ ] ホーム下段に「音の設定」が出て、sub にいまの段階（新しいセーブは `BGM 60% / SE 80%`）
- [ ] 押すとパネルが開き、BGM の −/＋ で曲の大きさがその場で変わる。0 で止まり「OFF」、＋ で再開
- [ ] SE の −/＋ を押すと、新しい大きさでタップ音が 1 回鳴る。OFF では鳴らない
- [ ] 閉じると sub が新しい段階になる。再読み込みしても残る。RTA 用のセーブにも引き継がれる（SPEC-123 のまま）
- [ ] 390×844 でパネルがはみ出さない
