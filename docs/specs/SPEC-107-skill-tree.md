## 1. 概要

CE で解放・強化するスキルツリー。ノード名は **MCH のスキル名**（エクステンションのアクティブスキル / ヒーローのパッシブスキル）。データは `web/src/data/tree.ts`。

## 2. データ

```ts
interface TreeNode {
  id; name /* MCH スキル名 */; source /* 出典 */;
  branch: "core" | "archer" | "defense" | "economy";
  pos: { x; y };            // ツリー座標（1 = 120px）。ルートが (0, 0)
  parent: string | null;    // 親を 1 レベル以上にすると購入可能
  maxLevel; cost: { token: "ce"; base; growth };  // 費用 = round(base × growth^現在レベル)
  effects: { stat: ModifierKey; perLevel }[];     // SPEC-108 の補正値
  icon;                     // MCH のバトルアイコン / GUM アイコン
}
```

## 4. 画面（スキルツリー）

- ドラッグで移動、ピンチ（PC はホイール）で拡大縮小（0.55〜1.6 倍）。行き過ぎないよう範囲を制限。
- ノード: MCH アイコン + レベル（`2/5`）+ スキル名。状態で見た目を変える（未到達 / 購入可能＝金枠 / 取得済み＝枝の色 / 最大＝金枠）。親子を線で結び、取得済みの線は枝の色。
- タップで下部に詳細: スキル名・出典・補足・現在の効果・次の効果・「解放 / 強化 N CE」・「返金」。未選択時は使用中 CE・累計 CE・「全返金」（確認つき）。
- 初回はマインちゃんが説明する（SPEC-108a）。

## 5. 受け入れ基準

- [x] ID 一意・親の存在・循環なし・全ノードがルートへ到達・コスト単調増加・ノードの重なりなし（データテスト）
- [x] 親が未解放 / CE 不足 / 最大レベルでは買えない（テスト）
- [x] スマホ縦で購入・返金・パン操作ができる（Playwright）
