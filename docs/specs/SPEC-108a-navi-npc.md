## 1. 概要

オリジナルキャラクター（戦闘には参加しない）による会話・案内の仕組み。立ち絵は `mycryptoheroes` の `Image/Characters` のコマをアニメーションで再生する（待機 = まばたき、話す = 口パク）。

## 2. 役割

| キャラクター | 役割 | 登場 |
|-------------|------|------|
| マインちゃん | ナビゲーター | 初回ラン（チュートリアル）、初回リザルト（CE とツリーの案内）、初回スキルツリー |
| クリスくん | 作戦参謀 | ステージ選択（初回の案内 + 毎回ランダムなヒント）、Lv2・Lv3 の初回ステージ紹介 |
| マイクリくん | 実況・記録係 | リザルトのひと言（勝敗・到達 Wave・獲得 CE） |

## 3. 仕組み

- 会話スクリプト: `web/src/data/dialogs.ts`（`{ speaker, text }` の配列）。
- `playDialog(scene, lines)`: 画面下部のメッセージウィンドウ + 立ち絵 + 名前札。文字送り（28ms/字）、タップで「表示完了 → 次へ」。再生中は下の画面を操作できない。ラン中はシミュレーションを一時停止する。
- `speechBubble(scene, speaker, …)`: 立ち絵つきの吹き出し（非モーダル）。
- 一度だけの会話は `SaveData.meta.seenDialogs` に既読を記録する。

## 4. 受け入れ基準

- [x] 初回ランでチュートリアルが出て、2 回目以降は出ない（Playwright で既読記録を確認）
- [x] ステージ選択・リザルト・スキルツリーで各キャラクターが表示される（スクリーンショット）
