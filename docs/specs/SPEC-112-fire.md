## 1. 役割

短い射程で**炎上を積み重ねる**持続ダメージ役。硬い敵・ボスに時間をかけて効く。弓の会心と組むと誘爆する。

## 2. 性能（Lv1）

| 項目 | 値 |
|------|-----|
| 配置 | 65 GUM（強化 60 / 95 / 155 / 240） |
| 攻撃 / 間隔 / 射程 | 1 / 0.25 秒 / 1.6 マス（Lv ごとに ×1.45 / ×0.97 / +0.1） |
| 炎上 | 1 命中で毎秒 0.8（× Lv 補正）を加算、3 秒、上限は 14 命中分 |
| 巻き込み | 標的から 0.6 マス以内の敵にも同じ炎上 |

## 3. ツリー（炎の系統）

| ノード（MCH スキル名） | 効果 |
|------------------------|------|
| 地雷火（猿飛佐助） | **解放** |
| 龍王の息吹 / ドラゴンクエイク / リュウガン | 炎上ダメージ +25% / 持続 +1 秒 / 射程 +0.25（各 Lv） |
| 暴君（皇帝ネロ） | **皇帝ネロに交代**。炎の攻撃力 +30%・射程 +0.3 |
| タイガーシュート | 弓の会心で、炎上中の敵が**誘爆**（炎上の毎秒ダメージ ×3） |
| 剣歯虎の一撃 | 炎の攻撃力 +20% / Lv |
| **伏爆の罠**（地雷） | 撃破した敵が 10% / Lv で**爆発**し、半径 1.2 マスの敵にその最大 HP の 40% ダメージ（連鎖あり） |

- 伏爆の罠は Outhold 解析レポート（ユーザー提供）の「爆弾歩兵（撃破時に周囲へ範囲ダメージ）」をプレイヤー側のノードとして取り込んだもの。分裂する敵（ラブレター）や密集した Wave に効く。

## 4. 受け入れ基準

- [x] 炎上を積み重ね、上限で止まり、継続ダメージを与える（テスト）
- [x] 弓の会心で炎上中の敵が誘爆する（テスト）
- [x] 撃破時の爆発が周りの敵にダメージを与え、リザルト集計（`blastDamage`）に入る（テスト）
