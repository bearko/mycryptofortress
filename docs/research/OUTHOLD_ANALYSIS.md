## 1. ゲーム概要

| 項目 | 内容 | 確度 |
|------|------|------|
| ジャンル | タワーディフェンス × インクリメンタル（メタ進行） | 【確定】 |
| コンセプト | 夜に襲来する敵から、拠点「Outhold」の**炎（Flame）**を守る | 【確定】 |
| ボリューム | 本編 **10 レベル**、約 4〜5 時間 + エンドゲーム（チャレンジ / プレステージ / エンドレス / アーティファクトレベル） | 【確定】 |
| チャレンジ数 | 10 レベル × 計 **50 チャレンジ** + New Game+ 的なプレステージ | 【確定】 |
| ビジュアル | ミニマル。敵は幾何図形（三角・星形など）、盤面は迷路状の経路 | 【確定】 |
| 評価 | Steam「非常に好評」（86% / 約 1,800 件）。 | 【確定】 |
| プラットフォーム | Steam（Win/Mac）、iOS / Android（買い切り・広告なし）、Web デモ（itch.io / Armor Games / galaxy.click） | 【確定】 |
| 開発経緯 | 2025-04 プロトタイプ → itch.io でデモ公開しつつ反復（v0.0.2〜v0.9.5）→ 2025-12 正式版 → 2026-03 大型無料更新（エンドレス / アーティファクトレベル / セーブスロット） | 【確定】 |

### 1.1 ゲームの核となる体験

1. レベルに挑む（ラン）→ 負けても**トークン**を獲得
2. トークンで**巨大なスキルツリー**のノードを解放
3. 強くなって再挑戦 →「あと 1 回だけツリーを組み替えて挑もう」というループ
4. **全ノードは無料で返金（リスペック）可能** → ビルド実験が推奨される設計
5. 1 つのタワーに特化する / タワー間シナジーを狙う、など**ビルドの多様性**が主題

## 3. ミクロゲーム（ラン内）仕様

### 3.1 盤面・経路

- 中央（または端）の**拠点 Outhold** に向かって、1〜複数の入口から敵が経路に沿って進行。【確定】
- 経路は迷路状。レベル 10 では **4 方向**から同時進行。【確定】
- タワーは**事前定義されたビルドマス（build slot）**にのみ設置できる。【確定】
  - レベル 4〜10 に追加マスが実装された経緯あり（例: Lv5 は入口直前に 2 マス + **光属性エンチャント済みマス** 2 つ）。【確定】
  - **属性付きマス（pre-enchanted slot）**: そこに置いたタワーは自動で元素エンチャントされる。【確定】
  - ラン中に**ゴールドで追加マス（タイル）を購入**できる（「早めに追加マスを買って Bank を早く稼働させる」攻略あり）。【有力】
- 地形を跳び越えて近道する敵（Leaper）が存在 → 経路外の地形も意味を持つ。【確定】

### 3.2 拠点 HP と被弾

| 項目 | 内容 | 確度 |
|------|------|------|
| 拠点 HP | 上限はおおむね **50 前後** | 【有力】 |
| 通常敵の到達 | 拠点 HP を削る（敵ごとのダメージ） | 【確定】 |
| **ボス到達** | **99 ダメージ = 実質即死** | 【有力】 |
| 回復手段 | Health Regen（固定値の自然回復。序盤最強だが後半スケールしない）/ 回復フィールド / ラン中の回復購入 | 【有力】 |
| 被弾トリガー | 「拠点が被弾すると炎の波動（Burning Vengeance）を放ち、Combust を誘発」等の反撃系ノード | 【確定】 |

### 3.3 Wave と進行

- 通常レベルは **Wave 制**。中盤 Wave にボス（例: エンドレス Lv2 は Wave 6 にボス）。【確定】
- **Wave スキップ**: 次 Wave を即時呼び出せる。残り未出現数に応じた**ボーナスゴールド**を得るが、敵に**Accelerated（加速）**が付与される。序盤に解放されるリスク/リターン要素。【確定】
- レベル 10（最終）は Wave なし。**撃破で満ちる完了メーター**方式で、全敵種・全ボスが 4 経路から押し寄せる。【確定】
- エンドレスモード: Wave 20 到達などが目標。後に「制限なし（unrestricted）」版をチェックボックスで選択可能に。【確定】

### 3.4 ゴールド（ラン内通貨）

- 敵撃破で**コインがドロップ**。**カーソルで拾う**必要があり、自動回収はアップグレードで解放。【有力】
- 追加獲得源: Bank タワー、Arrow の「命中ごとにコイン」ノード、Wave スキップボーナス、拠点周回の敵からの利息的収入。【有力】
- 用途: タワー購入 / レベルアップ / 追加マス購入 / **コインキャノン**の弾。【確定】
- 「コインを一定額貯め込む」がビルドチャレンジ条件になるほど、経済は主要ビルド軸。【確定】

### 3.5 タワー

| タワー | 役割 | 主な強化軸・派生 | 確度 |
|--------|------|------------------|------|
| **Arrow** | 基本単体攻撃 | 攻撃速度 / +2 本（マルチショット）/ **Heavy Arrow**（長射程・高威力のバリスタ化）/ 会心・**Multicrit** / 爆発確率・爆発ダメージ / 毒 / 命中ごとにコイン / マーク対象優先射撃 / **Light Arrows**（攻速↑・基礎威力↓）/ **Dancing Arrows**（レベルアップ毎に攻速↑・威力↓） | 【確定】 |
| **Lightning** | 近距離・連鎖 | 連鎖数↑ / 減衰率↓。命中で **Shock** を蓄積 → 閾値で **Discharge**（短時間スタン）。Arrow の派生として解放 | 【確定】 |
| **Pulse** | 範囲パルス | スロー（減速）主体。チャージ、火・毒との組み合わせで範囲状態異常ばら撒き。「Slow tower」とも呼ばれる | 【確定】 |
| **Fire** | 短射程・高火力 | **Burn**（スタック DoT）/ **Combust**（燃焼の追加爆発ダメージ）。光属性で遠射程の貫通火球（4 方向）に変化。Lv6 で登場 | 【確定】 |
| **Bank** | 経済 | 周囲を歩く敵から追加ゴールド、設置直後の「+20 ゴールド」強化が定番。各レーンに 1 基が攻略の定石 | 【確定】 |
| **Coin Cannon** | プレイヤー操作 | 所持ゴールドを弾として撃つ**手動照準**のアクティブ攻撃。「コインキャノンのみで倒す」チャレンジあり | 【確定】 |

補足:
- タワーはゴールドで**レベルアップ**。ホバーで次レベルの射程をプレビュー。**Auto Level**（自動レベルアップ、ラン中 ON/OFF 可）あり。Shift キーでまとめてレベルアップ。【確定】
- タワーごとの**累計ダメージ**をツールチップで確認可能。【確定】
- ターゲティングは「拠点に最も近い敵」を優先しない挙動への不満がある（奥の敵を撃ち続ける）→ 本プロジェクトではターゲット優先度を明示的に設計すべき論点。【有力】

### 3.6 状態異常・ダメージ種別

| 名称 | 効果 | 付与源 | 確度 |
|------|------|--------|------|
| **Burn** | 継続ダメージ。**常時スタック**（v1.0.4 以降）。1000 tick 超は効果逓減 | Fire / 火属性 | 【確定】 |
| **Combust** | 燃焼に上乗せの追加ダメージ（最大 N tick 分）。旧仕様は燃焼を消費する爆発だった | Multi-Combust（Multicrit→Combust 5tick）/ Arc Flash（Discharge→Combust 100tick）/ Disintegration Station（拠点被弾→15tick） | 【確定】 |
| **Poison** | 継続ダメージ（ボス対策の定番） | Arrow 毒ノード / 地属性 | 【確定】 |
| **Slow** | 移動速度低下 | Pulse / 氷属性 | 【確定】 |
| **Shock → Discharge** | 蓄積→閾値でスタン | Lightning | 【確定】 |
| **Vulnerable** | 被ダメージ増加（Exploited Vulnerability で強化） | ツリーノード | 【確定】 |
| **Mark** | マーク対象を優先射撃・追加効果 | ツリーノード | 【有力】 |
| **Stun / Knockback** | 移動停止 / 押し戻し | 氷属性 | 【確定】 |
| **Accelerated** | 敵の加速（デバフではなく敵側バフ） | Wave スキップ / 双子ボスの片割れ撃破 | 【確定】 |
| **Explosive** | 範囲爆発ダメージ（確率発動） | Arrow の爆発ノード群（ツリー各所に散在） | 【確定】 |
| **Critical / Multicrit** | 会心 / 多重会心 | Arrow・基本タワーノード | 【確定】 |

実績「Rough Day」＝ 1 体に Vulnerable / Burn / Slow / Shock / Poison を同時付与、が存在 → 状態異常は 5 系統が主軸。【確定】

### 3.7 敵

| 種別 | 特徴 | 確度 |
|------|------|------|
| 通常 | 標準速度・標準 HP | 【確定】 |
| **Runner** | 黄〜橙の三角。高速・低 HP | 【確定】 |
| **Leaper** | 緑のアスタリスク。**地形を跳び越えて近道**する | 【確定】 |
| **Lv5（Lv6）ボス: 双子三角** | 上向き/下向きの 2 体が別方向から侵攻。片方撃破で残りが**永続加速** | 【確定】 |
| **Lv8 ボス: 分裂ブロブ** | 低速スライム。ダメージで 2 分裂 → さらに分裂。1 体でも到達で即死 | 【確定】 |
| **Lv9 ボス: ワーム** | 複数セグメント。どの節を削っても本体 HP が減る → 多段/範囲攻撃が有効。HP 膨大 | 【確定】 |
| **Lv10: 全ボス総出** | 過去全ボスが 4 経路から襲来（HP は初登場時より低め） | 【確定】 |
| エンドレス | Wave ごとにスケール。経済を伸ばさないと追いつかない | 【確定】 |

その他の敵種（装甲・回復・シールド等）の存在は確認できず。【推定: 少数精鋭の敵種構成】

## 4. マクロゲーム（メタ進行）仕様

### 4.1 スキルツリー

- 「スプロール（蜘蛛の巣）状」の巨大ツリー。中心から枝が伸び、枝ごとにタワー / 経済 / 状態異常 / 拠点防御などのテーマを持つ。【確定】
- ノードは**レベル制**（1 ノードに複数段階）。v1.0.4 で必須系ノードの最大レベルが引き上げ。【確定】
- 前提ノードを満たさないと購入不可（v0.0.3 で「前提チェーンの資源不足でも奥のノードが買えた」バグ修正）。【確定】
- ノードごとに**要求トークン種**が異なる（例: Dancing Arrows は砂時計トークン）。上部のトークンアイコンをホバーすると、その種類のノードをハイライト。【確定】
- **トレードオフノード**: 何かを強化する代わりに別の何かが弱まる（Light Arrows 等）。【確定】
- **完全無料リスペック**（全返金。実績「Pivot」＝一括全リセット）。【確定】
- **ビルドセット**: 5 つのビルドを保存・切替（マイルストーン解放）。【確定】
- タワーは最初は Arrow のみ。ツリー経由で Lightning / Pulse / Fire / Bank / Coin Cannon / Heavy Arrow を解放。【確定】
- 予算制約上、1 周目で全系統は取れない（「Lightning 系を全部取ると Slow・Fire・Coin Shooter が買えない」）。【有力】

### 4.2 トークン（メタ通貨）

| トークン | 入手 | 確度 |
|----------|------|------|
| **三角トークン（基本）** | 通常プレイ（勝敗問わず、進行度に応じて） | 【確定】（デモ→製品版移行上限 10,000 三角トークン） |
| **砂時計トークン** | タイムトライアル達成 | 【確定】 |
| その他チャレンジ系トークン | ビルド特化 / トークン制限 / プレステージ等の達成報酬（「特殊トークンでより強力なノード」） | 【有力】（種類名は未確認） |

### 4.3 マイルストーン（自動化 / QoL の段階解放）

進行に応じて「作業を減らし戦略に集中させる」機能が解放される。【確定】

- Auto Level（タワー自動レベルアップ、ラン中トグル）
- 一括レベルアップ（Shift）
- コイン自動回収
- Wave スキップ
- Time Challenge（タイムトライアル解放）
- Build Sets（5 ビルド保存）

### 4.4 アーティファクト（元素エンチャント）

- 解放後、タワーに**元素をエンチャント**できる。元素は 5 種。【確定】
- 所持数に上限があり、各元素 1 個 → アーティファクトレベル（5 つ）クリアで各 2 個に。【確定】

| 元素 | 効果の方向性 | 確度 |
|------|-------------|------|
| **Earth（地）** | ダメージ増加 or **毒付与**。Lightning×地、Pulse×地（毒ばら撒き）が定番 | 【確定】 |
| **Fire（火）** | **燃焼付与** or ダメージ増加 | 【確定】 |
| **Ice（氷）** | スロー / スタン / ノックバック | 【確定】 |
| **Light（光）** | **射程大幅増 or ヒット数増**。Fire×光は短射程火炎放射→長射程貫通火球（4 方向）へ**挙動そのものが変化** | 【確定】 |
| **Wind（風）** | 攻撃速度 or 状態異常付与率の増加 | 【確定】 |

→ 「タワー 6 種 × 元素 5 種」でタワーの**挙動が変わる**組み合わせ設計がビルドの厚みを生んでいる。

## 7. 評価と課題（v2 設計で改善すべき点）

| 論点 | 内容 | v2 での方針案 |
|------|------|---------------|
| 序盤の強制グラインド | 「良いところに行く前の強制アップグレード作業がやや長い」（レビュー） | 序盤の要求トークンを緩め、1 時間以内に 3 種タワーを触れる曲線に |
| ターゲティング | 拠点に近い敵を優先しない | 「先頭 / 最強 / 最弱 / 最寄り」切替を初期から提供 |
| ツリーの情報欠落 | 最大化ノードの要求トークンが見えない | 常時表示 + フィルタ |
| CPU 負荷 | 高負荷の指摘 | オブジェクトプール・状態異常 tick 集約 |
| モバイル操作 | 小さいターゲットの操作性 | 縦画面・大きめタップ領域・長押しツールチップ |
| 自動化要望 | コイン自動回収 / 自動レベルアップ / プリセット要望 | マイルストーンで早期に解放 |
| バランス | Slow が強すぎ・爆発ボスが弱い等 | 数値はデータ駆動（JSON）で調整容易に |

## 8. v2 に取り込む「Outhold らしさ」の要件（抽出結果）

1. **負けても進む**: ラン結果に応じて必ずトークンが入る。
2. **無料リスペック**: ツリーはいつでも全返金。実験を罰しない。
3. **少数のタワー × 元素 × ツリーノード**の掛け算で挙動が変わる（数値強化だけでなく**挙動変化ノード**を用意）。
4. **状態異常の相互作用**（Burn→Combust、Shock→Discharge→Combust、Vulnerable 乗算）が中盤以降の主役。
5. **経済ビルド**（Bank / コイン命中 / Wave スキップ）と**火力ビルド**のトレードオフ。
6. **ボスはギミック型**（双子・分裂・多節）で、ビルドの弱点を突く。
7. **チャレンジで同じマップを再利用**し、異なるビルドを強制する（コンテンツ効率が高い）。
8. **マイルストーンによる自動化**でインクリメンタルらしい「手間が減っていく快感」。
9. **短く濃い**: 本編 4〜5 時間 + やり込み。
